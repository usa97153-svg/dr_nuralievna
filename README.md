# Dr. Nuralievna — Стоматология (Актобе)

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
npm run start
```

## Стек
Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion, lucide-react.

## Деплой на Vercel
```bash
npm i -g vercel
vercel
```
Или подключите репозиторий на vercel.com напрямую.
